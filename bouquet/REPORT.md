# 꽃다발 공방 앱: 조사·리스크·사업성 평가

작성일 2026-11-22. 프로토타입은 같은 폴더의 `index.html`입니다.

## 1. 프로토타입 범위

| 화면 | 기능 |
|---|---|
| 손님: 꽃다발 만들기 | 오늘 들어온 꽃 목록(가격·남은 수량) → 송이 단위로 담기 → 꽃다발 일러스트 실시간 미리보기 → 포장지 선택 → 꽃값+포장비 합계 → 주문서 전송 |
| 손님: AI 추천 (데모) | 용도·분위기·예산을 고르면 **오늘 재고 안에서만** 3가지 조합 제안. 메인 꽃은 홀수, 예산 안에서 배분 |
| 사장님 | 오늘의 사입 장부(꽃·색·모양·사입가·판매가·재고), 배율로 판매가 일괄 계산, 마진 표시, 들어온 주문(다발 그림 + 꽃별 송이 수 + 픽업 시간), 상태 변경·취소 시 재고 복구 |

**한계 (의도적으로 뺀 것)**
- 데이터가 브라우저에만 저장됩니다. 손님과 사장님이 같은 브라우저에서만 서로의 데이터를 봅니다.
- AI 추천은 규칙 기반 데모입니다. 실제 AI 모델을 호출하지 않습니다.
- "조합된 사진"은 SVG 일러스트입니다. 실제 사진도, AI 생성 이미지도 아닙니다.
- 결제, 알림(카톡), 로그인이 없습니다.

## 3. 문제점·리스크·장애물

### A. 사장님 운영 (가장 큰 리스크)
1. **매일 입력 부담.** 새벽 사입 후 품목·수량·가격을 매일 입력해야 합니다. 5분이 넘으면 지속되기 어렵습니다.
2. **재고 불일치.** 매장 판매·전화 주문이 앱 재고에 반영되지 않으면, 이미 팔린 꽃이 온라인에서 주문됩니다. 그러면 취소·대체 연락이 생기고 신뢰가 떨어집니다. POS 연동 없이는 구조적 문제입니다.
3. **단위 차이.** 사입은 '단(묶음)', 판매는 '송이'입니다. 송이마다 크기와 상태가 다르고, 시드는 손실분이 생깁니다. 송이당 고정가로는 손실 반영이 어렵습니다.
4. **가격 노출.** 꽃다발 가격에는 디자인·포장·인건비가 들어갑니다. 송이 단가를 공개하면 "꽃값만 보면 비싸다"는 비교와 마진 노출을 부릅니다. 프로토타입처럼 포장비만 따로 받으면 인건비가 빠집니다.
5. **디자인 책임.** 손님이 만든 어색한 조합도 결과물 불만은 꽃집 몫이 됩니다. 플로리스트의 핵심 가치(조합 감각)를 손님에게 넘기는 구조라 현장 거부감이 있습니다.

### B. 손님 경험
6. **선택 피로.** 대부분의 손님은 꽃 이름과 어울리는 조합을 모릅니다. 실제로는 "예산·용도만 말하고 맡기기"를 선호합니다.
7. **기대 불일치.** 미리보기와 실물은 다를 수밖에 없습니다. AI 생성 사진은 더 사실적이라 기대치를 더 높입니다. Noelle Fleur도 별도 경고문을 둡니다.
8. **낮은 구매 빈도.** 국민 1인당 화훼 소비액은 연 약 1.2만 원 수준이고 감소 추세입니다([농식품부 화훼산업육성 종합계획](https://www.mafra.go.kr/bbs/mafra/71/252544/download.do)). 재방문이 드물어 별도 앱 설치는 무리이고, 웹 링크면 충분합니다.

### C. AI
9. **환각.** 재고에 없는 꽃을 추천할 수 있습니다. 모델이 재고 목록 안에서만 고르도록 구조화 출력으로 강제해야 합니다.
10. **비용.** 추천 1회(입력 약 3천 토큰, 출력 약 1.5천 토큰, 1달러=1,400원 가정) 기준 Claude Haiku 5.5는 약 1.5원, Sonnet 5.5는 약 29원, Opus 5.5는 약 59원입니다. 한 매장 규모에선 작지만, 무제한 호출을 막는 장치는 필요합니다. 실제 사진 같은 이미지는 별도 이미지 생성 모델이 필요하고, 비용과 품질 리스크가 추가됩니다.
11. **표시 의무.** [인공지능기본법](https://m.korea.kr/news/policyNewsView.do?newsId=148958380)이 2026-01-22부터 시행되었습니다. 생성형 AI 서비스 제공 사업자는 AI 사용 사실을 미리 알리고 결과물에 표시해야 합니다. 1년 이상 계도기간이 있고, 위반 시 과태료가 최대 3천만 원입니다([법무법인 칼럼](https://bh-law.kr/ko/news/column/ai-content-labeling-obligation-guide)). "AI 추천", "AI 이미지" 표기가 필요합니다.

### D. 법·결제·운영 (전문가 확인 필요)
12. 온라인 결제를 받으면 통신판매업 신고, PG 계약, 주문 제작 상품의 청약철회 제한 고지를 검토해야 합니다.
13. 이름·연락처 수집에 따른 개인정보 처리방침이 필요합니다.
14. 노쇼·당일 취소 시 이미 자른 꽃을 어떻게 처리할지 예약금 정책이 필요합니다.

### E. 기술
15. 실서비스에는 서버 DB, 동시 주문 시 재고 잠금, 사장님 알림(카카오 알림톡 등), 관리자 로그인이 필요합니다. 프로토타입은 이 중 아무것도 없습니다.

### F. 시장·경쟁
16. **시장 축소.** 화훼 생산액은 2014년 7,019억 원에서 5,174억 원으로 약 26% 줄었습니다([농수축산신문](http://www.aflnews.co.kr/news/articleView.html?idxno=204161)).
17. 온라인 꽃 수요는 꽃배달 중개·구독 서비스가 이미 가져가고 있습니다.
18. 해외에서는 같은 기능이 무료 플랫폼의 일부입니다. 독립 SaaS로 차별화할 여지가 작습니다.

## 4. 냉정한 평가

| 사업 형태 | 상용화 가능성 | 이유 |
|---|---|---|
| 소비자용 독립 앱/플랫폼 (B2C) | **낮음 (10점 중 1~2)** | 구매 빈도 낮음, 고객 획득 비용 대비 객단가 작음, 꽃배달 플랫폼과 경쟁 |
| 전국 꽃집 대상 SaaS (B2B) | **낮음 (2~3)** | 사장님 입력 부담, 작은 꽃집의 낮은 지불 의사, 해외에선 무료 기능. POS 업체(토스플레이스 등)가 붙이면 바로 따라잡힘 |
| **우리 꽃집 한 곳의 차별화 기능** | **중간~높음 (6)** | 추가 비용이 거의 없음. "오늘 들어온 꽃"은 그 자체로 인스타·홈페이지 콘텐츠. 상담 시간 단축 효과는 Noelle Fleur 사례에서도 보고됨 |

**결론:** 독립 사업으로는 권하지 않습니다. **우리 가게의 주문 전 소통 도구**로는 해볼 만합니다.

**권장 방향 (피벗)**
- "손님이 직접 디자인"보다 **"오늘의 꽃 보여주기 → 예산·용도로 추천 → 사장님이 최종 확정"**을 기본 흐름으로 하고, 송이 직접 고르기는 선택 기능으로 둡니다.
- 가격은 "예상 가격"으로 표시하고, 사장님이 확정 금액을 회신합니다. 대체 꽃 동의 체크박스를 둡니다.
- 1단계는 결제 없이 **카카오톡 문의로 연결**합니다. 조합 내역과 그림을 담아 보냅니다.

**검증 지표 (2~4주)**
1. 사장님의 일일 재고 입력 시간 (목표 5분 이하)
2. 링크 방문 대비 주문 요청 수, 그중 실제 구매 전환율
3. 미리보기와 실물 차이로 인한 불만 건수
4. 추천 조합 사용 비율 대비 직접 조합 비율 (직접 조합이 거의 없으면 추천 중심으로 정리)
